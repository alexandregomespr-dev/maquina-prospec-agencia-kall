# 🎯 Máquina de Prospeção — Agência Kall Alexandre (v2.1.0)

**Plugin privado para Claude que corre o ciclo completo de prospeção de PMEs, redesenho de páginas (SGE/Google 2026) e publicação via Hostinger.**

## O que a automação faz

| Comando | Execução |
|---|---|
| `/setup` | Configura a sua assinatura, nichos ICP (advogados, clínicas, TI) e chaves da Hostinger. |
| `/prospectar` | Varre o Google Maps e isola PMEs com faturamento potencial e sites obsoletos. |
| `/redesenhar` | Recria as páginas injetando GTM, GA4 e Schema.org (mantendo a identidade do cliente). |
| `/publicar` | Faz o deploy seguro (FTPS) diretamente para o servidor da Hostinger. |
| `/proposta` | Cria o rascunho de e-mail focando no ROI e na infraestrutura técnica do novo site. |
| `/respostas` | Lê o Gmail e atualiza o CRM local quando o cliente responde. |
| `/followup` | Gera lembretes automáticos para propostas sem resposta há mais de 3 dias. |
| `/contrato` | Gera minuta de prestação de serviços travada (apenas para assinatura do cliente). |

## 📊 CRM Local
Painel focado em aquisição e MRR (lucro previsível). Aceda através do `iniciar-dashboard.bat` (requer Python instalado).
